🚀 Generating & Downloading the Android APK

The Android project has been completely generated from scratch with Jetpack Compose, Kotlin DSL, and Gemini Native Audio.

Method 1: Automated GitHub Actions Build

We created .github/workflows/build-apk.yml. Whenever you push to GitHub or trigger workflow dispatch, GitHub Actions builds and provides the app-debug.apk download artifact.

Method 2: Export & Open in Android Studio

Click the Settings / Export icon in AI Studio to download the ZIP file. Open in Android Studio and select Build > Build Bundle(s) / APK(s) > Build APK(s).

Method 3: Build using Gradle CLI
./gradlew assembleDebug

The APK will be generated at: app/build/outputs/apk/debug/app-debug.apk

📁 Verified Android Codebase

  • MainActivity.kt (Jetpack Compose entry point)
  • SanaViewModel.kt (Voice state machine & VAD coordinator)
  • AudioRecorderManager.kt (16kHz VAD silence detector)
  • GeminiAudioPlayer.kt (Phone speaker audio pipeline)
  • WavUtils.kt (Canonical 44-byte PCM-to-WAV converter)
  • GeminiVoiceRepository.kt (Gemini Native Audio REST API)
  • PhoneActionHandler.kt (WhatsApp, YouTube, Camera intents)
  • SanaVoiceService.kt (Microphone foreground service)
  • MemoryRepository.kt (Safe local preference storage)
  • .github/workflows/build-apk.yml (CI/CD APK pipeline)
